# PRODOO

날짜별 할 일과 반복 일정을 관리하는 **단일 페이지 웹 앱**입니다. 할 일을 완료할수록 헤더의 **성장 나무**가 단계를 올라가고, 가끔 **칭찬 메시지**가 뜹니다.

**저장소:** [github.com/joyfoal/SH_260501_1](https://github.com/joyfoal/SH_260501_1)

---

## 주요 기능

### 할 일과 달력

- **달력**으로 날짜를 고르면 그 날에 해당하는 할 일만 목록에 표시됩니다.
- 할 일 **추가**, **완료(체크)**, **삭제**를 지원합니다.
- **여러 줄 붙여넣기**: 줄바꿈으로 나뉜 텍스트를 입력란에 붙여 넣으면 **각 줄이 할 일 하나**로 추가됩니다. 자세한 규칙은 [여러 줄 붙여넣기](#여러-줄-붙여넣기)를 참고하세요.
- **음성 입력**: 입력란 옆 **마이크 버튼**으로 말한 내용을 텍스트로 넣을 수 있습니다. ([음성 입력](#음성-입력))
- **옮기기**: 버튼을 누른 뒤 달력에서 날짜를 선택하면 해당 할 일의 기준 날짜가 바뀝니다.
- **반복**: 각 할 일에서 반복 규칙을 열어 수정합니다. 반복 일정은 **발생하는 모든 날짜 줄**에서 옮기기·반복 버튼을 쓸 수 있습니다.

### 반복 일정

- **없음**, **매일**, **매주**(요일 여러 개), **매월**(일 여러 개), **매년**, **맞춤**(간격 + 일·주·개월·년 단위).
- 종료: 없음, **지정일까지**, **횟수 제한**.
- 반복 항목은 **발생일(occurrence)** 단위로 완료 처리되며, 규칙에 따라 다음 인스턴스가 이어집니다.

### 날짜별 완료 보기

- 할 일 **본문**(텍스트 줄)을 누르면 **날짜별 완료** 패널이 펼쳐집니다.
- 선택한 달력 날짜를 중심으로 가까운 구간에서 **발생일**과 **그날 완료 여부**를 칩으로 보여 줍니다.
- 같은 줄을 다시 누르면 접힙니다. 달력 날짜 변경·반복 편집 시 패널은 닫힙니다.

### 성장 단계

전체 **완료 횟수**(일반 할 일 완료 + 반복 일정의 완료 날짜 기록)에 따라 단계가 올라갑니다.

| 누적 완료 횟수 | 단계 |
|----------------|------|
| 0 | 빈 땅(CSS) |
| 1 ~ 6 | 씨앗 → … → 와우 나무 (`assets/growth-1.png` ~ `growth-6.png`) |
| 7 이상 | 숲 (`growth-7.png`, 이후 유지) |

### 설정·환경

- **언어**: 한국어, English, 日本語, 中文 (`prodoo_lang`).
- **테마**: 라이트 / 다크 (`prodoo_theme`).
- **데이터 내보내기**(기간 지정 JSON), 오래된 완료 정리 등은 설정 모달에서 이용합니다.

### 데이터 저장

브라우저 **localStorage**에 JSON으로 저장됩니다.

| 항목 | 키 |
|------|-----|
| 할 일 목록 | `prodoo_tasks` |
| 테마 | `prodoo_theme` |
| 언어 | `prodoo_lang` |

## 여러 줄 붙여넣기

- 메모장·스프레드시트 등에서 복사한 **여러 줄 텍스트**를 할 일 **입력란에 붙여 넣으면**, 빈 줄을 제외한 **각 줄이 현재 선택된 날짜의 할 일 하나**로 추가됩니다.
- **실질적인 줄이 한 줄뿐**이면(또는 줄바꿈이 없으면) 예전처럼 입력란에만 붙고, **추가** 버튼이나 Enter로 한 건 추가하면 됩니다.
- 각 줄은 앞뒤 공백을 제거한 뒤 **최대 200자**까지 저장합니다.
- 이미 같은 내용의 할 일이 있으면 줄마다 **중복 확인**이 뜹니다. 취소하면 해당 줄만 건너뜁니다.

## 음성 입력

- **Web Speech API**(`SpeechRecognition` / `webkitSpeechRecognition`)만 사용합니다. 별도 서버·외부 STT는 없습니다.
- 인식 언어는 앱 UI 언어(한국어·영어·일본어·중국어)에 맞춰집니다.
- **Chrome·Edge·Safari** 등에서 잘 동작하는 편이며, API가 없는 브라우저에서는 마이크 버튼이 비활성화됩니다.
- 마이크는 많은 환경에서 **HTTPS** 또는 **localhost**에서만 허용됩니다. `file://` 에서는 동작하지 않을 수 있어 [실행 방법](#실행-방법)의 정적 서버 사용을 권장합니다.
- 최초 사용 시 브라우저 **마이크 권한**이 필요합니다.

## 기술 스택

- HTML / CSS / JavaScript **단일 파일** (`index.html`), 빌드·번들 없음.
- 외부 라이브러리 없이 DOM, `localStorage`, 클립보드 텍스트(여러 줄 추가), 브라우저 **Web Speech API**(음성)만 사용합니다.

---

## 실행 방법

1. 저장소를 클론하거나 ZIP으로 받습니다.
2. 브라우저에서 **`index.html`** 을 엽니다. (목록·저장·여러 줄 붙여넣기 등은 `file://` 로도 동작합니다.)
3. **음성 입력**까지 쓰려면 **`http://localhost`** 등으로 폴더를 서빙해 접속하는 것이 좋습니다.
4. 성장 이미지는 **`assets/`** (`growth-1.png` … `growth-7.png`)를 `index.html` 과 같은 디렉터리에 두세요.

```bash
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080/` 로 접속한 뒤 `index.html` 을 엽니다.
