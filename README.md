# PRODOO

날짜별 할 일과 반복 일정을 관리하는 **단일 페이지 웹 앱**입니다. 할 일을 완료할수록 헤더의 **성장 나무**가 단계를 밟아가며, 짧은 **칭찬 메시지**로 피드백을 줍니다.

**저장소:** [github.com/joyfoal/SH_260501_1](https://github.com/joyfoal/SH_260501_1)

## 주요 기능

- **할 일 목록**  
  선택한 날짜의 할 일만 표시하고, 추가·완료·삭제·날짜 이동을 지원합니다.

- **달력**  
  월 단위 그리드에서 날짜를 선택해 해당 날의 일정으로 전환합니다. 일정이 있는 날에는 표시가 있습니다.

- **반복 일정**  
  없음, 매일, 매주(요일 다중 선택), 매월(일 다중 선택), 매년, **맞춤**(간격 + 일/주/개월/년 단위)을 지원합니다.  
  종료 방식: 없음, 지정일까지, 횟수 제한.

- **반복 작업의 완료**  
  반복 항목은 **발생일(occurrence)** 단위로 완료 처리되며, 완료 시 규칙에 따라 다음 인스턴스가 생성됩니다.

- **성장 단계 (8단계)**  
  전체 **완료 횟수**(일반 할 일의 `done` + 반복의 완료 날짜 기록)에 따라 단계가 올라갑니다.

  | 누적 완료 횟수 | 단계 |
  |----------------|------|
  | 0 | 빈 땅 (CSS만 사용) |
  | 1 ~ 6 | 씨앗 → 어린 새싹 → 무럭 나무 → 쑥쑥 나무 → 튼튼 나무 → 와우 나무 (`growth-1.png` ~ `growth-6.png`) |
  | 7 이상 | 숲 (`growth-7.png`, 이후에도 숲 유지) |

- **데이터 저장**  
  브라우저 **localStorage**에 JSON으로 저장됩니다. (키: `prodoo_tasks`)

- **설정**  
  기간별 데이터보내기(JSON), 오래된 완료 항목·전체 정리 등 보조 기능이 모달 안에 있습니다.

## 기술 스택

- HTML/CSS/JavaScript **단일 파일** (`index.html`), 빌드 도구 없음
- 외부 프레임워크 없이 DOM·`localStorage`만 사용

## 실행 방법

1. 저장소를 클론하거나 ZIP으로 받습니다.
2. 브라우저에서 `index.html`을 엽니다.  
   - `file://`로 열어도 동작합니다.  
   - 이미지·스타일 경로 문제가 있으면 같은 폴더에서 간단한 정적 서버로 여세요.  
     예: `python3 -m http.server 8080` 후 `http://localhost:8080/`에서 `index.html` 접속

## 프로젝트 구조

```
(클론한 폴더)/
├── index.html      # 앱 전체 (마크업·스타일·스크립트)
├── assets/         # 성장 단계 일러스트 (PNG)
│   └── growth-1.png … growth-7.png
├── README.md
└── .gitignore
```
